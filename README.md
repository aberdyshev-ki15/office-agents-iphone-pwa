# Офис агентов — PWA

Интерактивный автономный офис недвижимости Красноярска. Архивный снимок на 17.11.2026, без прямой синхронизации с ChatGPT.

Публикация: GitHub Pages из корня ветки `main` либо через workflow. Открыть в Safari → Поделиться → На экран «Домой».

> Внимание: данные объектов архивные; ставки, цены, правовой статус и доступность перепроверять перед любыми решениями. Персонажи не имитируют живую работу агентов.
